TaxSphere

CA · CMA · CS study and professional tools, by Sachin Sanwal

TaxSphere is an app for Android and Windows with syllabus tracking, concept notes, quizzes, income tax and GST calculators, GST return preparation (GSTR-1, GSTR-3B, Meesho), reckoners and Companies Act tools.

Most of the app works offline. Optional Google sign-in lets you back up your work to the cloud and keep purchases on every device.

Download TaxSphere 2.6

📱 Android app (APK, 1.3 MB) 💻 Windows app (ZIP, 80 MB)

Android: open the APK and allow "Install unknown apps" for your browser or file manager if asked.
Windows 10/11: right-click the ZIP → Extract All → double-click TaxSphere.exe. If Windows shows a warning, click More info → Run anyway.
After installing, TaxSphere updates itself automatically when you're online.
